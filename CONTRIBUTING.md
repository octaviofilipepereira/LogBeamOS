## Português

Contribuições são bem-vindas: correcções, melhorias, traduções, testes com outros rádios e equipamento, e relatórios de problemas.

### *Issues*

- Antes de abrir uma, veja se já existe uma igual.
- Indique a versão do LogBeamOS e das ferramentas (`apt policy logbeamos-ferramentas`), o rádio, o cabo ou a placa de som, se for o caso, o que esperava e o que aconteceu.
- Falhas de segurança **não** vão para as *issues*: ver [SECURITY.md](SECURITY.md).
- Pode escrever em português ou em inglês.

### *Pull requests*

1. Os *pull requests* são feitos para o ramo **`unstable`**. O `main` só recebe o que já foi verificado no `unstable`.
2. Uma alteração por *pull request*, com uma descrição do que muda e porquê.
3. Cada ficheiro fica na pasta onde é instalado (ver o [README.pt.md](README.pt.md#organização-do-repositório)).
4. Textos das janelas: sempre nas quatro línguas (PT, EN, ES, FR), na tabela de textos de cada ferramenta.
5. Datas DD/MM/AAAA e horas HH:MM em 24 h.
6. Não são permitidos segredos no código: chaves, passwords ou endereços internos.
7. Cada ficheiro novo começa com o cabeçalho de autoria e licença (GPL v3) que os restantes ficheiros já têm.

### Reconhecimento

Se quiser, o seu indicativo ou nome aparece nas notas da versão que inclui a sua contribuição. Basta indicá-lo na *issue* ou no *pull request*.

### Licença das contribuições

O projecto é distribuído com a [GNU General Public License v3.0](https://www.gnu.org/licenses/gpl-3.0.html). Ao enviar uma contribuição, aceita que seja distribuída com a mesma licença.

## English

Contributions are welcome: fixes, improvements, translations, tests with other radios and equipment, and problem reports.

### Issues

- Before opening one, check whether the same one already exists.
- State the version of LogBeamOS and of the tools (`apt policy logbeamos-ferramentas`), the radio, cable or sound card if relevant, what you expected and what happened.
- Security flaws do **not** go into issues: see [SECURITY.md](SECURITY.md).
- You may write in Portuguese or in English.

### Pull requests

1. Pull requests go to the **`unstable`** branch. `main` only receives what has already been checked on `unstable`.
2. One change per pull request, with a description of what changes and why.
3. Each file stays in the folder where it is installed (see the [README](README.md#repository-layout)).
4. Window texts: always in the four languages (PT, EN, ES, FR), in each tool's text table.
5. Dates DD/MM/YYYY and times HH:MM in 24 h.
6. No secrets in the code: keys, passwords or internal addresses.
7. Each new file starts with the authorship and licence header (GPL v3) that the other files already have.

### Credit

If you wish, your callsign or name appears in the release notes of the version that includes your contribution. Just mention it in the issue or pull request.

### Licence of contributions

The project is distributed under the [GNU General Public License v3.0](https://www.gnu.org/licenses/gpl-3.0.html). By sending a contribution, you agree that it is distributed under the same licence.
