Antes de instalar ao lado do Windows

Estes passos fazem-se no Windows, antes de arrancar pela pen.

  1. Faça uma cópia de segurança dos seus dados.
  2. Desligue a encriptação do disco. Definições → Privacidade e segurança → Encriptação do dispositivo → Desligar. Nas edições Pro: Painel de Controlo → Encriptação de Unidade BitLocker → Desactivar o BitLocker. Aguarde até terminar.
  3. Desligue o arranque rápido. Painel de Controlo → Opções de Energia → Escolher o que fazem os botões de energia → Alterar definições que estão actualmente indisponíveis → desmarque "Ligar o arranque rápido".
  4. Reinicie pela pen e escolha "Instalar LogBeamOS". Na página do tipo de instalação, escolha instalar ao lado do Windows.

Os passos 2 e 3 fazem-se com o «Preparar o Windows.cmd», que está na raiz da ISO: no Windows, faça duplo clique no ficheiro ISO para a abrir; depois, botão direito no ficheiro → «Executar como administrador».

Não é preciso alterar a BIOS: o Secure Boot pode continuar ligado. Depois de instalar, ao ligar o computador é apresentado um menu para escolher LogBeamOS ou Windows.

Before installing alongside Windows

Do these steps in Windows, before starting from the USB drive.

  1. Back up your data.
  2. Turn off disk encryption. Settings → Privacy & security → Device encryption → Off. On Pro editions: Control Panel → BitLocker Drive Encryption → Turn off BitLocker. Wait until it finishes.
  3. Turn off fast startup. Control Panel → Power Options → Choose what the power buttons do → Change settings that are currently unavailable → untick "Turn on fast startup".
  4. Restart from the USB drive and choose "Install LogBeamOS". On the installation type page, choose to install alongside Windows.

Steps 2 and 3 are done by «Preparar o Windows.cmd», at the root of the ISO: in Windows, double-click the ISO file to open it; then right-click the file → «Run as administrator».

There is no need to change the BIOS: Secure Boot can stay on. After installing, a menu lets you choose LogBeamOS or Windows when the computer starts.

Antes de instalar junto a Windows

Estos pasos se hacen en Windows, antes de arrancar desde la memoria USB.

  1. Haga una copia de seguridad de sus datos.
  2. Desactive el cifrado del disco. Configuración → Privacidad y seguridad → Cifrado de dispositivo → Desactivar. En las ediciones Pro: Panel de control → Cifrado de unidad BitLocker → Desactivar BitLocker. Espere hasta que termine.
  3. Desactive el inicio rápido. Panel de control → Opciones de energía → Elegir el comportamiento de los botones de inicio/apagado → Cambiar la configuración actualmente no disponible → desmarque "Activar inicio rápido".
  4. Reinicie desde la memoria USB y elija "Instalar LogBeamOS". En la página del tipo de instalación, elija instalar junto a Windows.

Los pasos 2 y 3 se hacen con «Preparar o Windows.cmd», que está en la raíz de la ISO: en Windows, haga doble clic en el archivo ISO para abrirla; después, clic derecho en el archivo → «Ejecutar como administrador».

No hace falta cambiar la BIOS: el Arranque seguro puede seguir activado. Después de instalar, al encender el ordenador aparece un menú para elegir LogBeamOS o Windows.

Avant d'installer à côté de Windows

Ces étapes se font dans Windows, avant de démarrer sur la clé USB.

  1. Sauvegardez vos données.
  2. Désactivez le chiffrement du disque. Paramètres → Confidentialité et sécurité → Chiffrement de l'appareil → Désactiver. Sur les éditions Pro : Panneau de configuration → Chiffrement de lecteur BitLocker → Désactiver BitLocker. Attendez la fin de l'opération.
  3. Désactivez le démarrage rapide. Panneau de configuration → Options d'alimentation → Choisir l'action des boutons d'alimentation → Modifier des paramètres actuellement non disponibles → décochez « Activer le démarrage rapide ».
  4. Redémarrez sur la clé USB et choisissez « Installer LogBeamOS ». Sur la page du type d'installation, choisissez d'installer à côté de Windows.

Les étapes 2 et 3 se font avec « Preparar o Windows.cmd », à la racine de l'ISO : dans Windows, double-cliquez sur le fichier ISO pour l'ouvrir ; puis clic droit sur le fichier → « Exécuter en tant qu'administrateur ».

Inutile de modifier le BIOS : le démarrage sécurisé peut rester activé. Après l'installation, un menu permet de choisir LogBeamOS ou Windows au démarrage de l'ordinateur.
